# 智能管家 v5

這是一個一個管家、多情境 PWA 原型。核心設計是「使用者不用研究功能，只要直接說或簡單輸入，管家會自動判斷、分類、整理、提醒與追蹤」。

## 一個管家總腦

本專案的最終定位不是多個分散 Agent，而是「一個智能管家」知道所有情境。

使用者面前永遠只有一個管家；投資、照護、個人、學生、老師、家庭、小生意情境都只是管家的不同情境能力。

管家總設定已整理在：

- `MASTER_BUTLER_PROMPT.md`

這份文件可直接作為 Coze / LINE Agent / 網頁 PWA 的總 Prompt 與 Knowledge Base 規劃依據。

核心原則：使用者不用研究功能，只要說話；管家負責判斷、分類、記錄、提醒與風險保護。
## 目前定位

- 個人情境：待辦、會議、採買、付款、聯絡、文件、健康事項
- 投資情境：持倉追蹤、觀察清單、交易紀錄、到價提醒、停損停利、市場分析、潛力分析、投資日記、風險檢查
- 長輩照護：血壓血糖、吃藥、看診摘要、家人通知
- 學生：作業、考試、報告、壓力提醒
- 老師：班務、批改、會議、家長聯絡
- 家庭：採買、家務、繳費、接送
- 小商家：訂單、出貨、收款、庫存

## 主要功能

- PWA：可部署到 Vercel，也可加入手機主畫面
- 簡單模式：只保留大按鈕與語音入口
- 管理模式：設定情境、自訂快捷鍵、查看摘要與資料工具
- 智慧記事：依語句自動分群，支援同一件事追加項目
- 主動提醒：任務到時間會提醒，並可追問是否完成
- 健康紀錄：支援血壓、血糖、健康警示與看診摘要
- 資料備份：可匯出與匯入本機資料
- 快取更新：Service Worker 採網路優先策略，降低手機卡舊版機率
- 投資安全邊界：目前只做紀錄與提醒，不串券商、不自動下單

## 投資紀律規劃

目前投資紀律定位為「投資紀律工具」，不是自動交易機器人。

可做：

- 記錄觀察標的與條件
- 記錄買賣價格、數量與理由
- 輸入買進成交內容時，自動建立持倉追蹤與平均成本
- 設定停損停利與到價提醒
- 標記高風險語句，例如槓桿、融資、期貨、選擇權、連續加碼
- 記錄前一天美股、利率匯率、地緣政治、產業題材等市場背景
- 建立潛力分析框架，從題材、基本面、技術面、估值與風險整理標的
- 內建每日市場早報、潛力分析、風險檢查模板
- 產生投資週報與決策回顧

暫不做：

- 不提供保證獲利建議
- 不直接推薦買賣
- 不串券商帳戶
- 不自動下單

後續可接資料源：

- 美股三大指數與費半
- 美股個股與 ETF 報價
- 美元、殖利率、油價、黃金
- 財經新聞與地緣政治摘要
- 台股個股、ETF、除權息與財報日期

資料源接入前，市場分析以手動筆記為主。

## 使用建議

- 手機請優先用 Chrome 或 Safari 開啟，不建議長期使用 LINE、Facebook、Instagram 內建瀏覽器。
- 若手機仍顯示舊版，請用 `/app?fresh=1` 測試，或刪除舊的主畫面捷徑後重新加入。
- 個人情境適合先做 MVP；真正商用化時，再接後端資料庫、LINE Login、Web Push、通知服務與權限管理。


## v5.4.5 投資紀律現價追蹤
- 支援輸入：今天買台積電 5 股 920 元，停損 880，停利 980。
- 支援輸入：台積電現價 930，自動更新持倉現價、估算損益、檢查停損停利。
- 目前只做紀律提醒與紀錄，不自動下單；未來可再接行情 API 與券商只讀/交易授權。


## v5.4.6 投資紀律觀察清單
- 支援輸入：加入觀察台積電，AI 題材，等到 900 以下再看，風險是美股轉弱。
- 未買進前會以觀察中管理，記錄等待價、潛力分數、題材與風險。
- 買進同一檔標的後會整合到原本觀察資料，不會拆成兩筆。


## v5.4.7 投資紀律今日雷達
- 將原本投資週報升級為今日雷達，依優先度整理持倉、觀察清單、現價、等待價、停損停利與市場筆記。
- 會標示今日優先看哪些標的，例如碰到停損、接近停利、到等待價、尚未更新現價。
- 報告再次強調只做紀律提醒與風險整理，不是買賣建議，也不自動下單。


## v5.4.8 投資紀律提醒排程
- 新增開啟/關閉投資提醒，預設提醒 08:30 今日雷達、14:10 收盤現價更新、21:30 投資日記整理。
- 新增 10 秒測試提醒，可立即確認語音、頁面提醒與瀏覽器通知是否可用。
- 提醒仍屬本機 PWA 層級，App 關閉或手機省電限制可能影響通知；正式商用可再接伺服器排程與 LINE Notify/官方訊息。


## v5.4.9 投資紀律價格新鮮度
- 支援一次更新多檔現價，例如：台積電現價 930，鴻海現價 210，0050 現價 185。
- 持倉與今日雷達會顯示現價更新時間，超過 3 天未更新會標示價格過期。
- 今日雷達會把價格過期、尚未更新現價、接近停損停利的標的提高優先度。


## v5.5.0 投資紀律交易紀律
- 每筆持倉新增紀律分數，檢查買進理由、部位大小、成交/均價、停損、停利、最大可虧損。
- 支援輸入交易理由，例如：今天買台積電 5 股 920 元，停損 880，停利 980，理由 AI 需求成長。
- 今日雷達會把紀律不足的持倉提高優先度，提醒先補齊交易計畫，不自動提供買賣指令。


## v5.5.1 投資紀律資金控管
- 新增總資金、單筆最大可虧損、單檔投入上限百分比設定。
- 每筆持倉會顯示投入佔比與資金控管提醒，超標會在今日雷達提高優先度。
- 風控只做紀律提醒，不會產生自動下單或強制買賣建議。


## v5.5.2 投資紀律交易確認
- 不完整買進會標記為待確認交易，提醒補齊停損、停利、理由、部位大小或最大可虧損。
- 支援後續補資料，例如：台積電停損 880，停利 980，理由 AI 需求成長。
- 今日雷達會把待確認交易提高優先度，避免不完整計畫被當成正式交易紀錄。


## v5.5.3 投資紀律日記情緒
- 新增投資日記與情緒紀錄，可辨識 FOMO、追高、焦慮、貪心、後悔、冷靜等標籤。
- 支援輸入：今天買台積電有點 FOMO，但停損停利都有照計畫。
- 今日雷達會把最近有情緒風險的標的提高優先度，提醒先檢查紀律與資金控管。


## v5.5.4 投資紀律策略模板
- 內建策略模板：回檔買進、突破買進、高股息長期持有。
- 支援輸入：台積電套用回檔買進策略。
- 持倉與今日雷達會顯示策略名稱與缺漏條件，例如等待價、突破價、停損、停利、理由。


## v5.5.5 一個管家介面
- 將使用者可見語感統一成「智能管家」，不再讓使用者感覺有多個分散工具。
- 情境仍保留個人、投資紀律、長輩情境、學生、老師、家庭、小生意情境，但都由同一個管家判斷與整理。
- 介面按鈕與提示改成「跟管家說」「讓管家整理」，符合一句話入口設計。


## v5.5.6 管家情境入口
- 將首次選擇與情境下拉改成「管家優先照顧哪一塊」，降低工具切換感。
- 補上提示：不確定也可以直接說話，管家會自己判斷情境。
- 將剩餘「秘書」語感收斂成智能管家與投資紀律等情境能力。

## v5.5.7 管家總覽
- 首頁新增「想到什麼，直接跟管家說」，清楚說明使用者不必先選對情境。
- 以能力標籤呈現生活、照護、投資、讀書、家庭與小生意都由同一個管家處理。
- 新增可點選的自然語句範例，點一下即可帶入記事輸入框。
- 修正投資儀表板持倉區標題的文字編碼顯示。
## v5.5.8 管家自動分流
- 「優先照顧情境」改為偏好，不再是功能限制；同一個管家會依內容自行判斷情境。
- 在任何模式都能辨識投資交易、現價、觀察、策略、日記與風險內容。
- 血壓與血糖數字從統一記事入口輸入時，會直接存入健康紀錄。
- 自動辨識健康照護、投資紀律、學生讀書、老師班務、家庭生活與小生意內容，並顯示分流結果。
## v5.5.9 管家主動追問
- 使用者只說一半時，管家會先保存，再追問一個最重要的缺漏。
- 支援提醒時間、訂單數量、投資數量、成交價與觀察條件追問。
- 回答符合上一題格式時自動補回原紀錄；突然換話題時不強行合併。
- 追問保留 24 小時，可按「先不用」略過。
## v5.6.0 肉粽訂單唯讀連接
- 新增 Vercel /api/order-summary，透過伺服器端環境變數讀取肉粽系統 Supabase。
- 前端只取得未結案、今日、逾期、宅配與未收款摘要，不取得電話、地址或品項明細。
- 家人管理頁可設定專用連接密碼、手動更新摘要並開啟完整訂單系統。
- 訂單 API 不進入 Service Worker 快取，降低客戶資料殘留風險。

## v5.7.0 一問總覽

- 使用者直接說「今天要做什麼」「有沒有重要的事」或「管家報告一下」，不需要尋找功能按鈕。
- 管家會整合進行中待辦、訂單急件與未收款、最近健康紀錄、投資風險提醒。
- 總覽問題只會回答，不會誤存成新的記事卡。
